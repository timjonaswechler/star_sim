# Star Sim Debug

Use `star_sim_debug` to run one logical or rendered Star Sim Controlled Session from its human REPL, inspect session state, collect failure diagnostics, and prepare GitHub issue reports. Read [`../../apps/star_sim_debug/README.md`](../../apps/star_sim_debug/README.md) before running it. Read [`../../crates/automation_control/README.md`](../../crates/automation_control/README.md) when integrating or consuming the reusable crate.
