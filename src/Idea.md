# Idea for Star-Sim

- A Systems position will be determined by a seed.
- With this Position the probability of the Star configurrations is set (live time and so)
- the Systems propability for a stable star formation will be determined out of that
- Barycenter is defined and will be used to determine the star's position (updates by adding other objects)
- objects will be added to the system and their mass will be used to update the barycenter
  - out of the postion to the star's position the Object properties will be set ( rocky ... )
  - the objects will gets an extra detail run to set their properties after all the objects have been added

we need reasearch for formulas to determine the star propability distribution and so on
we need research for formulas to determine the objects and starts properties
